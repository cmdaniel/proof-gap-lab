## What the compiler emitted

The proof covers the DSL source. These are what actually ran.

**baseline (compiled)**

```python
def transfer(src, dst, amount):
    fee_due = -(-(amount * 25) // 10000)
    ok = 0 < amount and amount + fee_due <= src
    new_src = src - (amount + fee_due) if ok else src
    new_dst = dst + amount if ok else dst
    fee = fee_due if ok else 0
    return (new_src, new_dst, fee,)
```
