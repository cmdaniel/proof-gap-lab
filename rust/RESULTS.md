## What the compiler emitted

The proof covers the DSL source. These are what rustc compiled and ran.

**baseline (compiled)**

```rust
pub fn baseline(src: i64, dst: i64, amount: i64) -> (i64, i64, i64) {
    let fee_due = -(-(amount * 25)).div_euclid(10000);
    let ok = 0 < amount && amount + fee_due <= src;
    let new_src = if ok { src - (amount + fee_due) } else { src };
    let new_dst = if ok { dst + amount } else { dst };
    let fee = if ok { fee_due } else { 0 };
    (new_src, new_dst, fee)
}
```
